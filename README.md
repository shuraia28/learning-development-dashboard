# Training Analytics Dashboard - Power BI

This project showcases a Training Analytics Dashboard developed using Microsoft Power BI. The dashboard is designed to help HR and Learning & Development (L&D) teams monitor training effectiveness, analyze training investments, and evaluate employee participation across multiple companies and departments.
# Tools Used
- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Modeling
- Interactive Data Visualization

The dashboard supports strategic workforce development decisions by providing actionable insights into organizational learning and development initiatives.

This dashboard is a **Training & Development Analytics Dashboard** designed to provide management with a comprehensive view of employee training activities, training costs, training hours, employee distribution, and training status across different companies and departments.

# 1. Dashboard Purpose

The primary objective of this dashboard is to monitor:

* Employee participation in training programs
* Training hours delivered
* Training expenditure
* Training type distribution
* Internal vs. external training status
* Company-wise workforce distribution
* Quarterly training cost trends

This dashboard enables HR, Learning & Development (L&D), and management teams to make data-driven decisions regarding employee development and training investments.
